## Questions / Discussion points

- regex-syntax has a function `is_meta_character`, which does not contain
  `!`, `=` and `<` and adding these would be a breaking change. It is unclear,
  however, whether these would need to be added. In particular, it is unclear
  what the consequences would be for the `\<` word half boundary escape sequence
- it is unclear how one could implement the captureless lookbehind algorithm
  without introducing changes to the regex-automata crate, as the crate does not
  seem to enable hooking into the simulation steps.
