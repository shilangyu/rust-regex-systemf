# Documentation of the Rust regex crate project

- `Literature/` - some links and summary of the relevant literature
- `MeetingNotes/` - notes for the weekly meetings with a supervisor
- `ProgressTracking/` - weekly progress notes from authors
- `Proposal/` - the project proposal document and presentation
- `ImplementationPlan.md` - the plan of implementation of features

The current fork of `rust-lang/regex` can be [found here](https://github.com/Multimodcrafter/rust-regex). The targeted branch is `captureless-lookbehinds`.
